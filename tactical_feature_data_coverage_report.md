## Required Data Sources

To activate the engine, each Premier League team-match needs event or team-stat rows with:

- possession share
- passes and progressive passes
- pass length / long-ball counts
- possession sequences
- defensive actions by pitch zone
- pressure events and pressure outcomes
- turnovers and counterpress events
- crosses, through balls, counterattacks
- defensive blocks, interceptions, tackles
- event coordinates where possible
- event timestamps where possible

Typical source categories:

- paid event-data provider
- public event-data sample where available
- manually maintained team-match tactical CSV
- scraped team match stats, where legally and technically allowed
